# 三视图逆向重建：part.dwg（U 型槽支座）

## 输入
- 原始：`part.dwg`（AC1032 / AutoCAD 2018），16.6 KB
- 转换：`accoreconsole.exe` 执行 DXFOUT → `part.dxf`（R2018 ASCII）
- 解析：ezdxf 1.4.5，Model 布局 30 实体（27 LINE / 1 ARC / 2 CIRCLE）
- 图层语义：Outlines(实线) / Hidden(虚线) / Centerlines(中心线) / Dimensions(空)
- 单位：$INSUNITS=6（毫米），$MEASUREMENT=1（公制）
- 范围：EXTMIN(-2,-38) → EXTMAX(54,25)

## 读图→参数映射

### 主视图（x 0–30, y 0–22，x=宽, y=高）
- 底座轮廓：(0,0)-(30,0)-(30,8)-(0,8) → 底座宽 30、高 8
- 上部两侧竖壁：(0,8)-(0,22)-(5,22) 与 (25,22)-(30,22)-(30,8) → 立板宽 30，顶高 22
- 顶部半圆拱 ARC：中心(15,22) R10，180°→0° → 半圆槽半径 10，槽底 y=22−10=12
- 隐藏线 (7.5,0)-(7.5,8)、(22.5,0)-(22.5,8) → 两孔，中心 x=7.5 / 22.5，贯穿底座高 8
- 中心线 x=15 → 对称中心

### 侧视图（x 40–54, y 0–22，x=深, y=高）
- 底座：(40,0)-(54,0)-(54,8)-(48,8)-(48,22)-(40,22) → 底座深 14(40→54)、高 8；立板深 8(40→48)、顶高 22
- 隐藏线 (40,12)-(48,12) → 槽底 y=12（与主视图 22−10=12 一致 ✓）
- 隐藏线 (43,4)-(51,4) → 孔内底/孔轴示意
- 中心线 y=4 → 孔轴高（孔沿竖直方向，轴在俯视平面）

### 俯视图（x 0–30, y −35…−21，x=宽, y=深）
- 外轮廓：(0,-35)-(30,-35)-(30,-21)-(0,-21) → 底座宽 30、深 14
- 内矩形：(5,-21)-(5,-29)-(25,-29)-(25,-21) → 立板深 8（-29→-21 = 8）
- 两圆：中心(7.5,-28) R4、(22.5,-28) R4 → 2×Ø8 孔，孔深向位置 y=-28（距前边 -35 为 7 = 底座深/2）
- 中心线 x=15、y=-28 → 对称

## 交叉一致性校验
| 校验 | 结果 |
|---|---|
| 总高：22 = 底座 8 + 立板 14 | ✓ |
| 槽底：主视 22−R10=12 = 侧视隐藏线 y=12 | ✓ |
| 立板深：侧视 48−40=8 = 俯视 -21−(-29)=8 | ✓ |
| 孔位 x：主视 7.5/22.5 = 俯视 7.5/22.5 | ✓ |
| 孔深向位置：俯视 -28 距前边 7 = 底座深/2 | ✓ |
| 孔径：R4 → Ø8，主视隐藏线间距 15 = 7.5+7.5 | ✓ |

## 消歧判定
- 主/俯视图宽向对称（中心线 x=15），侧视图深向非对称（立板靠前）——非回转体，但为**基本体叠加 + 定向切除**，三视图信息充分，可唯一重建。
- 孔：主视隐藏线贯穿底座高 8、俯视为圆 → 竖直通孔，贯穿底座。无盲孔证据，判为通孔。
- 槽：主视为上开口半圆、侧视为内部隐藏线（槽不切透立板全长？）——侧视隐藏线仅到 x=48（立板后缘），槽贯穿立板整个深度 8。
