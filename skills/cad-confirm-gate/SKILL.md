# Skill: cad-confirm-gate（确认门协议）

你执行一次**确认门**：针对当前规格层，产出一个可让用户明确裁决的交互回合。完整协议见 `<工作区>/_cad_workflow/confirm-gate-protocol.md`。

## 六步节奏（不可跳步）

1. **提问**：针对当前层，给 2~3 个**具体**候选（带关键尺寸/形态描述），而非开放问题。
2. **生成**：调用 `cad-blender-ops`（或对应引擎技能）让 MCP 产出候选几何。至少让候选在形状上可区分。
3. **回传证据**：向用户展示——
   - 预览截图（MCP 视口截图文件路径，用 Markdown 图片语法内联）；
   - 关键尺寸（长×宽×高，mm）；
   - 面数 / 顶点数；
   - 水密状态（watertight 与否）。
   **没有证据不算完成。**
4. **用户裁决**：请用户明确选择：选某个候选 / 修改 / 再出候选 / 回退上一层。
5. **写回并锁定**：把裁决写进 `model-spec.md` 对应层，置 `[LOCKED]`；同步 `params.json`；存检查点。
6. **推进**：仅当该层 `[LOCKED]` 后，通知 `cad-spec-driver` 进下一层。

## 裁决处理表

| 用户裁决 | 动作 |
|---|---|
| 选定候选 A | 写回 + lock + 检查点 + 进下一层 |
| 混合 / 修改 | 记录修改点，重出候选，回步骤 2 |
| 都不满意 | 重新发散 2~3 候选，回步骤 1 |
| 回退上一层 | 目标层改回 `[PENDING]`，作废其后所有层，回目标层 |

## 硬规则

- 用户沉默 ≠ 同意；必须收到明确裁决才锁定。
- 每次裁决在决策日志留痕，附用户原话或候选编号。
- 预览/尺寸/校验必须来自 MCP 或脚本实测，不得用文字描述冒充证据。
- 回退时检查点不删除，保证可追溯。
- 一轮只确认一层，不跨层打包确认。

## 输出格式（给用户）

```
【确认门 · L<层>】<层名>
候选 A：<一句话描述 + 关键尺寸>
候选 B：…
候选 C：…
证据：<预览图> ｜ 尺寸 a×b×c mm ｜ 面数 N ｜ 水密：是/否
请回复：选 A / 选 B / 改（说明）/ 再出候选 / 回退 L<上一层>
```
