# 架构说明：六层栈 + 逐级确认

## 一、六层能力栈

```
L6 交付    Bambu Studio 切片 → .3mf/.gcode.3mf → H2D        [cad-verify + Bambu]
L5 交互    你 ↔ DSH Agent 对话、确认门、追问、回退           [cad-confirm-gate]
L4 编排    逐级拆解、状态机、版本检查点                       [cad-spec-driver]
L3 状态    单一事实源 spec.md / params.json + 工程检查点       [模板]
L2 桥接    MCP server / 后台 runner：建改查几何、回传证据      [cad-blender-ops / cad-freecad-ops]
L1 引擎    Blender（造型件） / FreeCAD（功能件 B-rep）         [本机软件]
```

**收益**：换引擎只动 L1-L2，换交互只动 L5，方法论与规格格式稳定。

## 二、三层角色

- **大脑**：DSH Agent + skills——理解意图、拆解、维护规格、发起确认、决定下一步。
- **手脚**：建模软件 + MCP bridge——创建/修改/查询几何、回传状态与预览。
- **事实源**：`model-spec.md` + `params.json` + 工程文件——可回退、复现、审计。

## 三、逐级确认（渐进式收敛）

`model-spec.md` 四层，每层带状态：
- **L0 大方向**：这是一类什么东西（戒指 / 垫片 / 支架）。
- **L1 结构分解**：由哪些部件/特征组成。
- **L2 特征**：每个部件的关键特征与拓扑。
- **L3 参数**：具体尺寸、公差、材料。

每层状态 `[LOCKED]` / `[PENDING]` / `[OPEN]`；推翻已锁层需显式回退（写决策日志）。

### 确认门六步节奏
1. AI 提出 2~3 个候选（含参数）。
2. 经 MCP / runner 生成几何。
3. 回传预览（截图）+ 尺寸/面数/水密等证据。
4. 用户裁决：确认 / 选一个 / 修改 / 回退。
5. 写入 spec 并把该层标 `[LOCKED]`，存检查点（v1_base 等）。
6. 进入下一层；无确认不深入。

## 四、双引擎路由

- 造型 / 手办 / 有机形状 → **Blender**（网格/雕刻灵活，MCP 实时已验证）。
- 功能件 / 装配 / 公差件 → **FreeCAD**（参数化特征树 + OCCT B-rep 精确 + STEP）。

路由写在 `model-spec.md` 元信息 `_engine`，决定调用 `cad-blender-ops` 还是 `cad-freecad-ops`。

## 五、FreeCAD 三通道与「更优路线」研判

| 通道 | 机制 | GUI | 适用 |
|---|---|---|---|
| A 代码即模型 headless（推荐） | `FreeCADCmd.exe` + 脚本，B-rep + STEP | 否 | 精确功能件、批量、可复现 |
| B MCP headless | `mcp__freecad__execute_code_headless` | 否 | 临时脚本 |
| C MCP 实时 | `mcp__freecad__execute_code`（RPC 9875） | 是 | 视口/FEM/装配交互 |

研判依据（Forgent3D 2026-10、CADGenBench）：AI 驱动精确 CAD 的头部方案是"代码即模型"（build123d/CadQuery/headless），MCP 本质是遥控器。故功能件优先走 headless 代码路线。

## 六、打印性校验边界（不伪造 PASS）

自动门槛（trimesh，仅管闭合三角网格）：水密 `is_watertight`、法线一致 `is_winding_consistent`、体积为正。
- trimesh 读 STL 必须合并顶点（`process=True` / `merge_vertices()`），否则重复顶点造成假阴性。
- 壁厚**不能**用最近顶点距离当代理（那测的是网格边长）→ 一律 `MANUAL_REQUIRED`，交 Blender 3D Print Toolbox → Thin Walls。
- B-rep 精确（4 面）≠ STL 轻量（OCCT 离散成 22 万面/68MB）；交付切片按需求选路线。

## 七、证据链

每次建模产出 `<stem>.build-evidence.json`（参数、dims、面数、非流形边/valid/closed、体积、manifold_pass）；`verify_stl.py` 产出三道门槛 + verdict。决策日志与检查点使全过程可审计、可回退。
