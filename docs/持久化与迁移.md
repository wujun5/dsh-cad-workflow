# 持久化、重启行为与迁移

## 一、DSH 重启后逐组件行为

| 组件 | 存储位置 | 重启 DSH | 重启 Blender/FreeCAD | 说明 |
|---|---|---|---|---|
| 5 个 skill | `~/.dsh/skills/<name>/SKILL.md` | 自动加载 | 无关 | 全局持久 |
| 2 个 bundle | `~/.dsh/profiles/<profile>/node_modules/@local/` | 自动加载、`apply` 重建 MCP 客户端 | 无关 | profile 持久 |
| MCP 客户端进程 | 由 bundle 的 stdio 命令拉起 | 自动重启 | 无关 | DSH 启动时连 |
| Blender addon server | Blender GUI 内，localhost:9876 | 需 DSH 重启后已连 | **需手动 Start Server** | addon 启用状态持久，Server 按钮不持久 |
| FreeCAD addon RPC | FreeCAD GUI 内，127.0.0.1:9875 | 同上 | **需手动 Start RPC Server** | 仅实时通道需要 |
| FreeCAD headless | FreeCADCmd 独立进程 | 无关 | 无关 | 每次调用新进程，最稳 |

**最小手动操作清单**（重启 Blender/FreeCAD 后）：
1. Blender：N 面板 → MCP → Start MCP Server（9876）。
2. FreeCAD（仅实时通道）：MCP Addon workbench → Start RPC Server（9875）。
3. DSH：从托盘完全退出再开，确认 `mcp__blender__get_addon_status` / `mcp__freecad__get_rpc_status`（实时通道）通过。

若只用 **headless 路线**（功能件）和 **bpy 后台路线**（造型件），则上述 GUI 步骤全可省略——这是推荐给无人值守/CI 的配置。

## 二、为什么 skill / bundle 持久

- DSH 的 skill 从 `DSH_HOME/skills` 全局发现，与当前打开的工作区无关，刷新 catalog 即可见。
- bundle 经 `dsh plugin --profile <p> add <dir>`（底层 pnpm add <dir>）注册：在 profile 的 `package.json`/`pnpm-lock.yaml` 写入 `@local/<name>` 的 `link:` 依赖，并在 `node_modules/@local/` 下建到仓库目录的 Junction。profile 的 `cordis.patch.yml` 引用其 `insert` 行，DSH 启动时加载并 `apply`——因此重启后自动恢复 MCP 工具。**注意：Junction 指向仓库目录，移动/删除仓库会使 bundle 失效，需 remove 后重装。**

（依据：DSH `dsh-doc` skill 的 mcp-bundle.md / configuration.md / host-plugin.md。）

## 三、迁移到新机器 checklist

- [ ] 安装 DSH（同 profile 名，如 desktop）。
- [ ] 安装 Blender / FreeCAD / Python(trimesh) / uv。
- [ ] `uvx --python 3.11 mcp-for-blender install-addon`（Blender 实时通道）。
- [ ] 复制 freecad-mcp addon 到 FreeCAD Mod 目录（FreeCAD 实时通道）。
- [ ] clone 本包 → 复制并填写 `my-env.json`（本机 uvx/FreeCADCmd/DSH_HOME/profile）。
- [ ] `install\doctor.ps1` → `install\configure.ps1`（渲染本机绝对路径到 `_rendered/`）。
- [ ] `install\install.ps1`（复制 skill + `dsh plugin add` 注册两个 bundle）。
- [ ] 完全重启 DSH → 点 GUI Start Server（headless 可免）→ `get_addon_status` / `get_rpc_status` 验证。
- [ ] 跑一遍 examples/washer-test.json 的最小闭环确认。

## 四、故障排查

| 症状 | 可能原因 | 处理 |
|---|---|---|
| skill catalog 看不到 cad-* | 装错目录 / 未刷新 | 确认 `~/.dsh/skills/<name>/SKILL.md` 有 frontmatter；重启/刷新 DSH |
| `mcp__blender__*` 工具不存在 | bundle 装错 profile / 仓库移动致 Junction 断 | 查 `node_modules/@local/` Junction 指向；在正确 profile 重跑 `install.ps1` |
| `Could not connect to Blender` | GUI server 未启动 | N 面板 Start MCP Server |
| `get_rpc_status` 报错 | FreeCAD RPC 未启动 | GUI 点 Start RPC Server，或改用 headless 通道 |
| FreeCAD 参数中文报 GBK 解码错 | CLI 传参 | 一律用 `CAD_PARAMS`/`CAD_OUT` 环境变量 |
| `__main__` guard 不触发 | FreeCADCmd exec 加载 | runner 底部直接 `main()` |
| 产物写到旧工作区 | 用了旧版硬编码脚本 | 换用本包路径无关脚本 |
| STL 68MB 过大 | OCCT 离散精度高 | 交付切片用 Blender mesh 路线，或用 FreeCAD STEP 保留参数化 |
