# 三视图 → 3D 最小原型（台阶法兰）

本记录证明：带尺寸标注的三视图可通过本包的参数化路线精确重建为可打印实体，且端到端已实测跑通。

## 问题定位

"用三视图生成 3D"不是 CAD 的现成功能：
- TechDraw 是 3D → 工程图（反方向）。
- 三视图重建是病态问题（同一视图对应多形体），学术研究（ENSAM、CAD Journal、ICCV2023 PlankAssembly）方向可信但无成熟通用开源工具链。

因此本原型采用 **路线 A：参数化精确重建**——把三视图当作一种 L5 输入，读尺寸后落到 L3 `params.json`，复用既有 FreeCAD headless 链路。

## 输入（examples/three-view/）

- `flange-3view.svg`：带尺寸标注的矢量三视图（主/俯/左，4px/mm）。选择 SVG 是因为当前模型不支持图像输入，矢量文本可读、可审计。
- `flange-3view-spec.md`：读图→参数对照表 + L0-L3 + 消歧说明。
- `flange-3view-params.json`：建模参数。

读图映射（长对正、高平齐、宽相等）：

| 观测 | 参数 | 值(mm) |
|---|---|---|
| 主视图底座宽 / 俯视外圆 | base_d | 40 |
| 主视图底座高 | base_h | 8 |
| 主视图凸台宽 / 俯视中圆 | boss_d | 24 |
| 主视图凸台高 | boss_h | 10 |
| 俯视内圆 / 主视虚线 | hole_d | 10 |

一致性校验：主视图总高 18 = 8 + 10 ✓。主/左视图轮廓相同 + 俯视同心圆 → 判定回转体 → 5 参数唯一确定（无歧义）。

## 执行（两条命令）

```powershell
# 1) FreeCAD headless 建模（runner 已扩展 shape=stepped_flange）
$env:CAD_PARAMS = '...\examples\three-view\flange-3view-params.json'
$env:CAD_OUT    = '...\output'
& 'D:\Program Files\FreeCAD 27.1\bin\FreeCADCmd.exe' '...\scripts\build_freecad_from_params.py'

# 2) trimesh 可打印性校验
& 'D:\Program Files\anaconda3\python.exe' '...\scripts\verify_stl.py' '...\output\flange-3view-spec-freecad.stl'
```

## 实测结果（2026-11-17）

| 项 | 值 |
|---|---|
| B-rep dims | [40.0, 40.0, 18.0] mm |
| B-rep faces | 6（精确解析面）|
| valid / closed / solids | true / true / 1 |
| volume | 13163.273 mm³ |
| manifold_pass | true |
| STL | 2748 三角面，watertight + winding + volume 全过 → **AUTO_PASS** |
| 产物 | `flange-3view-spec-freecad.stl` / `.step` / `.build-evidence.json` |

壁厚仍列 MANUAL_REQUIRED（交 3D Print Toolbox），未伪造 PASS。

## 结论与边界

- 带尺寸标注、可判定为回转体/基本体组合的三视图 → 可精确重建，直接进切片送 H2D。
- 若图纸含斜面/相贯线/非对称切除等无法由三视图判定的特征 → 需在 L2 请用户补充，不臆断。
- 无尺寸的剪影/照片 → 走路线 B（视觉外壳），只能得外形超集，会丢孔/凹坑。

## 复用

新增零件：复制 `examples/three-view/` 模板，改 SVG 尺寸标注、spec 对照表、params 数值；若为非回转体基本体组合，在 `build_freecad_from_params.py` 的 `build_shape()` 增加对应 shape 分支（参照 `stepped_flange`）。
